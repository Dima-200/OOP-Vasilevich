## Опис реалізації

Клас `Student` призначений для зберігання інформації про студента: його імені, ідентифікатора та середньої оцінки.

Властивість `AverageMark` має валідацію. Допустимим є значення від 0 до 100.

У класі реалізовано два конструктори:

* конструктор за замовчуванням, який створює студента зі стандартними значеннями;
* параметризований конструктор, який дозволяє передати ім'я, ID студента та середню оцінку.

Для уникнення дублювання коду використовується ланцюговий виклик конструкторів через `: this()`.

Метод `GetStudentCard()` повертає інформацію про студента.

Також реалізовано деструктор, який демонструє завершення життєвого циклу об'єкта.

## Життєвий цикл об'єкта

Життєвий цикл об'єкта складається з трьох основних етапів:

1. **Створення** — оператор `new` створює об'єкт та викликає відповідний конструктор.
2. **Використання** — об'єкт використовується програмою доти, доки існує посилання на нього.
3. **Знищення** — коли посилань на об'єкт не залишається, він стає доступним для видалення збирачем сміття.

Для навчальної демонстрації роботи збирача сміття використовуються `GC.Collect()` та `GC.WaitForPendingFinalizers()`.

## Перевірка валідації

Для властивості `AverageMark` встановлено обмеження: середня оцінка повинна бути в межах від 0 до 100.

Якщо встановити значення, яке виходить за допустимий діапазон, програма повідомляє про помилку.

## Ланцюговий виклик конструкторів

Конструктор за замовчуванням викликає параметризований конструктор за допомогою `: this()`.

Це дозволяє повторно використовувати код параметризованого конструктора та уникнути дублювання ініціалізації полів.

## Деструктор

У класі `Student` реалізовано деструктор (фіналізатор), який виконується збирачем сміття перед остаточним видаленням об'єкта.

Деструктори в C# використовуються рідко та переважно призначені для роботи з некерованими ресурсами.
