# Лабораторна робота №7

### **Тема:** Приховування методів (`new`) vs перевизначення (`override`).

### **Мета роботи**

Зрозуміти різницю між приховуванням методів за допомогою ключового слова `new` та перевизначенням методів через `virtual` / `override`, навчитися створювати ієрархію класів та демонструвати поліморфну поведінку об'єктів.

### **Варіант:** 3 — Ієрархія `Employee → Manager / Intern`

### **Базовий клас:** `Employee`

* **Властивість:** `Name` — ім'я працівника.
* **Конструктор:** приймає ім'я працівника.
* **Метод:** `virtual void Work()` — виводить повідомлення про виконання роботи працівником.

### **Похідний клас:** `Manager`

* успадковує клас `Employee`;
* конструктор викликає конструктор базового класу за допомогою `base`;
* метод `Work()` перевизначений за допомогою `override`;
* метод `HoldMeeting()` демонструє додаткову функціональність менеджера.

### **Похідний клас:** `Intern`

* успадковує клас `Employee`;
* конструктор викликає конструктор базового класу за допомогою `base`;
* метод `Work()` прихований за допомогою `new`;
* метод `Learn()` демонструє додаткову функціональність стажера.

# **Хід роботи**

### 1. Створення проєкту

Було створено консольний проєкт **lab7v3** у директорії `OOP-Vasilevich`.

Для розробки використовувалось середовище **Visual Studio Code** та **.NET SDK**.

### 2. Створення базового класу Employee

Відповідно до варіанту було створено базовий клас **Employee**.

Клас містить властивість `Name`, яка зберігає ім'я працівника.

Також було створено конструктор:

```csharp
public Employee(string name)
{
    Name = name;
}
```

Для демонстрації поліморфізму було створено віртуальний метод `Work()`:

```csharp
public virtual void Work()
{
    Console.WriteLine($"{Name}: Employee is working.");
}
```

Ключове слово `virtual` дозволяє похідним класам перевизначити цей метод.

### 3. Створення класу Manager

Після цього було створено похідний клас **Manager**, який успадковує `Employee`.

Конструктор класу викликає конструктор базового класу за допомогою `base`:

```csharp
public Manager(string name) : base(name)
{
}
```

Метод `Work()` було перевизначено за допомогою `override`:

```csharp
public override void Work()
{
    Console.WriteLine($"{Name}: Manager is managing the team.");
}
```

Також було створено додатковий метод `HoldMeeting()`:

```csharp
public void HoldMeeting()
{
    Console.WriteLine($"{Name}: Manager is holding a meeting.");
}
```

### 4. Створення класу Intern

Далі було створено похідний клас **Intern**, який також успадковує `Employee`.

Конструктор класу використовує `base`:

```csharp
public Intern(string name) : base(name)
{
}
```

Для демонстрації приховування методу було створено власну реалізацію `Work()` з ключовим словом `new`:

```csharp
public new void Work()
{
    Console.WriteLine($"{Name}: Intern is doing practical tasks.");
}
```

Також було створено додатковий метод `Learn()`:

```csharp
public void Learn()
{
    Console.WriteLine($"{Name}: Intern is learning.");
}
```

### 5. Демонстрація роботи через посилання базового класу

У методі `Main()` було створено об'єкти класів `Employee`, `Manager` та `Intern`:

```csharp
Employee employee = new Employee("Олександр");
Employee manager = new Manager("Дмитро");
Employee intern = new Intern("Іван");
```

Після цього було викликано метод `Work()`:

```csharp
employee.Work();
manager.Work();
intern.Work();
```

Результат:

```text
=== Виклик через посилання базового класу ===
Олександр: Employee is working.
Дмитро: Manager is managing the team.
Іван: Employee is working.
```

У випадку `Manager` спрацював механізм `override`, тому через посилання типу `Employee` викликався метод `Manager.Work()`.

У випадку `Intern` використовується `new`, тому через посилання типу `Employee` викликався метод `Employee.Work()`.

### 6. Демонстрація роботи через посилання похідних класів

Для порівняння було створено посилання безпосередньо на похідні класи:

```csharp
Manager manager = new Manager("Дмитро");
Intern intern = new Intern("Іван");
```

Після виклику:

```csharp
manager.Work();
intern.Work();
```

отримано:

```text
=== Виклик через посилання похідного класу ===
Дмитро: Manager is managing the team.
Іван: Intern is doing practical tasks.
```

У цьому випадку для `Intern` викликається саме його метод `Work()`, тому що тип посилання — `Intern`.

### 7. Демонстрація додаткових методів

Для класу `Manager` було викликано метод:

```csharp
manager.HoldMeeting();
```

Для класу `Intern`:

```csharp
intern.Learn();
```

Результат:

```text
=== Додаткові методи похідних класів ===
Дмитро: Manager is holding a meeting.
Іван: Intern is learning.
```

### 8. Порівняння `override` та `new`

У лабораторній роботі було практично продемонстровано різницю між `override` та `new`.

`override` використовується для перевизначення віртуального методу базового класу та забезпечує поліморфізм.

`new` використовується для приховування методу базового класу. При використанні `new` результат залежить від типу посилання.

| `override`                                   | `new`                                 |
| -------------------------------------------- | ------------------------------------- |
| Перевизначає метод базового класу            | Приховує метод базового класу         |
| Забезпечує поліморфізм                       | Не забезпечує поліморфізм             |
| Метод визначається за реальним типом об'єкта | Метод визначається за типом посилання |
| Потребує `virtual` у базовому класі          | Не потребує `virtual`                 |


# **Висновок**

Під час виконання лабораторної роботи було створено ієрархію класів `Employee`, `Manager` та `Intern`.

Було реалізовано віртуальний метод `Work()` у базовому класі `Employee`. У класі `Manager` цей метод було перевизначено за допомогою `override`, що дозволило продемонструвати поліморфізм при зверненні до об'єкта через посилання базового класу.

У класі `Intern` метод `Work()` було приховано за допомогою `new`. Було продемонстровано, що при зверненні через посилання типу `Employee` викликається метод базового класу, а через посилання типу `Intern` — метод похідного класу.

Також було реалізовано додаткові методи `HoldMeeting()` та `Learn()`.

У результаті роботи було закріплено знання про наслідування, поліморфізм, `virtual`, `override` та `new`, а також практично досліджено різницю між перевизначенням та приховуванням методів у C#.
