# Лабораторна робота №16, варіант 3: Студенти та оцінки

**Тема:** LINQ: `SelectMany`, пагінація та власні методи розширення.  
**Проєкт:** `lab16v3` — консольний застосунок .NET 10.

## Мета роботи

Навчитися розгортати вкладені колекції за допомогою `SelectMany`, розбивати дані на сторінки методами `Skip` і `Take`, а також створювати власний метод розширення для обчислення середнього бала.

## Сутності та тестові дані

- `Student` містить ідентифікатор, ім'я та вкладений список оцінок `Grades`.
- `Grade` містить предмет і отриманий бал.
- `Subject` містить ідентифікатор і назву предмета.
- Наведено 12 студентів, 4 предмети та 36 оцінок.

## Реалізація завдань

1. `SelectMany` розгортає оцінки всіх студентів в один список; у результаті збережено також ім'я студента для кожної оцінки.
2. Пагінація показує список студентів сторінками по 5 записів. Остання сторінка містить решту записів.
3. `AverageScore()` — метод розширення для `IEnumerable<Grade>`. Він повертає середнє арифметичне оцінок, а для порожньої послідовності повертає `0`.

## Контрольні питання

1. **Для чого потрібен `SelectMany` і чим він відрізняється від `Select`?**  
   `Select` перетворює кожен елемент у результат, тому при вибірці вкладеної колекції отримуємо послідовність послідовностей. `SelectMany` додатково об'єднує ці вкладені послідовності в одну. Наприклад, `students.Select(s => s.Grades)` дає колекцію списків оцінок, а `students.SelectMany(s => s.Grades)` — одну послідовність усіх оцінок.

2. **Як реалізувати пагінацію за допомогою LINQ?**  
   Для сторінки з номером `page` (нумерація від 1) і розміром `pageSize` пропускають `(page - 1) * pageSize` елементів через `Skip`, а потім беруть `pageSize` елементів через `Take`.

3. **Що таке методи розширення і як вони пов'язані з LINQ?**  
   Це статичні методи, які можна викликати як методи екземпляра типу. Перший параметр позначають `this`. LINQ використовує такі методи для операцій над `IEnumerable<T>`, зокрема `Where`, `Select`, `Skip` і `Take`.

4. **Наведіть приклад власного методу розширення для `IEnumerable<T>` і поясніть його призначення.**  
   У цій роботі `AverageScore(this IEnumerable<Grade> grades)` обчислює середнє значення поля `Score` у послідовності оцінок. Це дозволяє записати `student.Grades.AverageScore()` і повторно використовувати бізнес-логіку.
