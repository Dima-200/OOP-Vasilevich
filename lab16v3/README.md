
# Лабораторна робота №16

## Тема
LINQ: SelectMany, пагінація й custom extensions.

## Варіант №3
Студенти та їхні оцінки з предметів.

## Мета роботи
Навчитися використовувати оператор SelectMany для роботи
з вкладеними колекціями, реалізовувати пагінацію даних
за допомогою LINQ та створювати власні методи розширення.

## Опис класів

1. **Student** — клас студента, містить:
   - Id — ідентифікатор;
   - Name — ім'я студента;
   - Grades — список оцінок.

2. **Grade** — клас оцінки, містить:
   - Subject — навчальний предмет;
   - Score — отриманий бал.

3. **Subject** — клас навчального предмета, містить:
   - Id — ідентифікатор;
   - Name — назву предмета.

## Виконання завдань

### Завдання 1. SelectMany

За допомогою SelectMany отримано всі оцінки
всіх студентів в одному списку.

Для кожної оцінки виводиться ім'я студента,
назва предмета та отриманий бал.

### Завдання 2. Пагінація

Реалізовано пагінацію за допомогою методів Skip()
та Take().

На одній сторінці відображається 5 студентів.
Загалом створено 3 сторінки:
- Сторінка 1 — 5 студентів.
- Сторінка 2 — 5 студентів.
- Сторінка 3 — 2 студенти.

### Завдання 3. Custom Extension

Створено власний метод розширення AverageScore()
для обчислення середнього бала студента.

Метод приймає IEnumerable<Grade> та повертає
середнє арифметичне всіх оцінок.

Якщо оцінок немає, метод повертає 0.

## Контрольні питання

### 1. Для чого використовується оператор SelectMany?
Наведіть приклад, що демонструє його відмінність від Select.

SelectMany використовується для об'єднання вкладених
колекцій в одну послідовність.

Select повертає окрему колекцію для кожного елемента,
а SelectMany розгортає вкладені колекції в одну.

Приклад:
students.Select(student => student.Grades);
students.SelectMany(student => student.Grades);

### 2. Як реалізувати пагінацію даних за допомогою LINQ?
Які методи для цього використовуються?

Для пагінації використовуються методи Skip() та Take().

Skip() пропускає певну кількість елементів,
а Take() отримує потрібну кількість елементів.

Наприклад:
students.Skip(5).Take(5);

Цей запит повертає другу сторінку з п'яти студентів.

### 3. Поясніть концепцію методів розширення.
Як вони інтегруються з LINQ?

Методи розширення дозволяють додавати нові методи
до вже існуючих типів без зміни їхнього вихідного коду.

Вони оголошуються у статичному класі,
а перший параметр методу містить ключове слово this.

LINQ також використовує методи розширення
для роботи з колекціями, наприклад Where(),
Select(), SelectMany(), Skip() та Take().

### 4. Наведіть приклад власного методу розширення
для IEnumerable<T> та поясніть його призначення.

У роботі реалізовано метод AverageScore()
для IEnumerable<Grade>.

Він обчислює середнє арифметичне оцінок студента
за допомогою методу Average().

Це дозволяє повторно використовувати логіку
обчислення середнього бала для різних студентів.
