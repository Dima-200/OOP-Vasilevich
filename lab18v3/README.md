# Лабораторна робота №18

## Тема
Власні винятки та патерн Result.

## Варіант
3 — обробка файлів.

## Мета роботи
Навчитися створювати власні класи винятків, використовувати механізм `try-catch` та реалізовувати патерн `Result` для обробки помилок без постійного генерування винятків.

## Виконання роботи

У ході лабораторної роботи було створено консольний застосунок мовою C#.

Реалізовано такі компоненти:

- **InvalidFileFormatException** — власний клас винятку для обробки файлів неправильного формату. Містить властивості `FileName` та `ExpectedFormat`.
- **Result<T>** — узагальнений клас, який зберігає інформацію про успішне виконання операції або помилку.
- **FileProcessorService** — сервіс для читання та запису файлів.
- **ReadFile(path)** — перевіряє розширення файлу та генерує `InvalidFileFormatException`, якщо формат не відповідає очікуваному.
- **WriteToFile(path, content)** — записує дані у файл та повертає об'єкт `Result<bool>`.

### Результати виконання

**1. Перевірка читання файлу**

Файл `example.txt` було успішно прочитано. Під час спроби прочитати файл `example.csv` було перехоплено власний виняток `InvalidFileFormatException`.

**2. Перевірка запису файлу**

Метод `WriteToFile()` успішно записав дані у файл `output.txt` та повернув результат `True`.

**3. Перевірка патерну Result**

Метод `Result<bool>.Failure()` створив результат невдалого виконання. Властивість `IsSuccess` повернула `False`, а властивість `Error` містила інформацію про помилку.

## Відповіді на контрольні запитання

**1. Що таке власні винятки та для чого вони потрібні?**

Власні винятки — це класи, створені програмістом для опису специфічних помилок програми. Вони дозволяють точніше визначати причини помилок та зручніше їх обробляти.

**2. Які переваги має використання власних винятків?**

Власні винятки роблять програму зрозумілішою, дозволяють передавати додаткову інформацію про помилку та відокремлювати різні типи проблем.

**3. У чому полягає патерн Result?**

Патерн Result передбачає повернення спеціального об'єкта, який містить або успішний результат операції, або інформацію про помилку. Це дозволяє обробляти очікувані помилки без використання винятків для кожної ситуації.

**4. Чим відрізняються винятки від патерну Result?**

Винятки використовуються для сигналізації про помилки через механізм `throw` та `catch`. Патерн Result повертає результат операції як звичайний об'єкт, у якому можна перевірити `IsSuccess` та отримати `Error`.
