# Самостійна робота №1

## Тема

Базовий синтаксис C# і оголошення класів.

## Мета роботи

Закріпити навички оголошення класів, полів, властивостей та методів у C# для моделювання об'єктів реального світу.

## Завдання

* Створити новий консольний проєкт `IndependentWork1`.
* Оголосити 2–3 нових класи, яких не було у списку варіантів до лабораторної роботи.
* Для кожного класу створити мінімум 2 приватних поля.
* Створити мінімум 1 публічну властивість з `get` та `set`.
* Додати конструктор для ініціалізації полів.
* Реалізувати мінімум 1 метод, який виконує певну логіку.
* У методі `Main()` створити по одному екземпляру кожного класу.
* Викликати методи класів та вивести результати їх роботи в консоль.

## Створення проєкту

Проєкт було створено за допомогою команди:

```text
dotnet new console -o IndependentWork1
```

Назва проєкту:

`IndependentWork1`

## Реалізовані класи

У роботі створено три класи:

* `Book` — книга.
* `BankAccount` — банківський рахунок.
* `Car` — автомобіль.

Класи є власними сутностями та не повторюють приклад `Product` з методичних рекомендацій.

## Клас Book

Клас `Book` призначений для моделювання книги.

### Приватні поля

* `_title` — назва книги.
* `_author` — автор книги.
* `_pages` — кількість сторінок.

### Властивості

* `Title` — назва книги.
* `Author` — автор книги.
* `Pages` — кількість сторінок, доступна тільки для читання.

### Конструктор

Конструктор `Book` приймає назву книги, автора та кількість сторінок і записує ці дані у відповідні поля.

### Методи

* `IsLongBook()` — перевіряє, чи має книга 300 або більше сторінок.
* `PrintInfo()` — виводить інформацію про книгу.

## Клас BankAccount

Клас `BankAccount` призначений для моделювання банківського рахунку.

### Приватні поля

* `_owner` — ім'я власника рахунку.
* `_balance` — баланс рахунку.

### Властивості

* `Owner` — власник рахунку.
* `Balance` — поточний баланс, доступний тільки для читання.

### Конструктор

Конструктор `BankAccount` приймає ім'я власника та початковий баланс.

### Методи

* `Deposit()` — поповнює баланс рахунку.
* `PrintInfo()` — виводить інформацію про рахунок.

## Клас Car

Клас `Car` призначений для моделювання автомобіля.

### Приватні поля

* `_brand` — марка автомобіля.
* `_fuel` — кількість пального.
* `_fuelConsumption` — витрата пального на 100 км.

### Властивості

* `Brand` — марка автомобіля.
* `Fuel` — кількість пального.

### Конструктор

Конструктор `Car` приймає марку автомобіля, кількість пального та витрату пального.

### Методи

* `CalculateDistance()` — розраховує можливу відстань, яку автомобіль може проїхати на наявному пальному.
* `PrintInfo()` — виводить інформацію про автомобіль.

## Демонстрація роботи програми

У методі `Main()` створено по одному об'єкту кожного класу:

```csharp
Book book = new Book("Кобзар", "Тарас Шевченко", 350);

BankAccount account = new BankAccount("Іван Петренко", 5000);

Car car = new Car("Toyota", 40, 8);
```

Для книги викликається метод перевірки кількості сторінок:

```csharp
book.PrintInfo();
```

Для банківського рахунку демонструється поповнення балансу:

```csharp
account.Deposit(1500);
```

Для автомобіля виконується розрахунок можливої відстані:

```csharp
car.CalculateDistance();
```

Розрахунок виконується за формулою:

```text
(40 / 8) × 100 = 500 км
```

## Контрольні запитання

### 1. Які мінімальні елементи повинен містити клас у цьому завданні?

Кожен клас повинен містити мінімум два приватних поля, хоча б одну публічну властивість з `get` та `set`, конструктор для ініціалізації полів та хоча б один метод, який виконує певну логіку.

### 2. Чому поля доцільно робити приватними, а доступ до них надавати через властивості?

Приватні поля приховують внутрішній стан об'єкта та не дозволяють безпосередньо змінювати його ззовні. Властивості забезпечують контрольований доступ до даних та дозволяють виконувати додаткові перевірки.

### 3. Для чого в класі потрібен конструктор і як він пов'язаний зі станом об'єкта?

Конструктор використовується під час створення об'єкта для початкової ініціалізації його полів. Завдяки конструктору об'єкт одразу отримує необхідний початковий стан.

### 4. Як у Main показати, що методи класу працюють коректно?

У методі `Main()` потрібно створити об'єкти класів, викликати їхні методи та вивести результати роботи в консоль. У цій роботі продемонстровано перевірку книги, поповнення банківського рахунку та розрахунок можливої відстані автомобіля.
