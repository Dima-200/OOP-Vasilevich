# Лабораторна робота №4

### **Тема:** Властивості та статичні члени. Індексатори й перевантаження операторів.

### Варіант: 3 — Клас Money

* **Поля:** `_amount` (decimal), `_currency` (string).
* **Властивості:** `Amount`, `Currency`.
* **Статичний член:** `DefaultCurrency`.
* **Конструктор:** параметризований конструктор, який приймає суму та валюту.
* **Методи:** `ToString()`, `Equals()`, `GetHashCode()`.
* **Оператори:** `+`, `*`, `==`, `!=`.
* **Валідація:** сума не може бути від'ємною, валюта не може бути порожньою.
* **Індексатор:** не використовується, оскільки клас `Money` представляє одну грошову суму, а не колекцію.

# **Хід роботи:**

### Було встановлене середовище розробки VS Code з усіма необхідними розширеннями: C# Dev Kit; .NET Install Tool.

### Було створено консольний проєкт `lab4v3` у директорії `OOP-Vasilevich`. Відповідно до варіанту створив клас **Money**.

Клас містить: **Приватні поля:** суму `_amount` та валюту `_currency`.

**Публічні властивості для доступу до полів:** `Amount` та `Currency`. Властивість `Amount` містить перевірку, яка не дозволяє встановити від'ємну суму. Властивість `Currency` перевіряє, щоб значення валюти не було порожнім.

**Статичний член:** `DefaultCurrency`, який містить валюту за замовчуванням — `UAH`. Цей член належить самому класу та є спільним для всіх його об'єктів.

**Конструктор:** параметризований конструктор, який приймає суму та валюту і встановлює відповідні властивості.

**Перевантаження операторів:** реалізовано оператор `+` для додавання двох грошових сум. Додавання дозволяється тільки для однакових валют.

Також реалізовано оператор `*` для множення грошової суми на число.

Оператори `==` та `!=` використовуються для порівняння двох об'єктів `Money` за сумою та валютою.

**Перевизначені методи:** `ToString()` використовується для зручного виведення грошової суми, `Equals()` — для логічного порівняння об'єктів, а `GetHashCode()` — для отримання хеш-коду об'єкта.

**Індексатор:** у класі `Money` індексатор не використовується, оскільки цей клас представляє одну грошову суму, а не набір елементів.

Створив клас **Program**. У методі **Main()** було створено декілька об'єктів класу **Money** з різними сумами та валютами.

Для об'єктів було продемонстровано зміну властивостей, використання статичної властивості `DefaultCurrency`, додавання сум за допомогою оператора `+`, множення суми за допомогою оператора `*`, а також порівняння об'єктів за допомогою операторів `==` та `!=`.

Також було продемонстровано роботу методів `Equals()` та `GetHashCode()`.

Для перевірки валідації було виконано спробу встановити від'ємну суму. Програма перехопила помилку та вивела відповідне повідомлення.

Також було перевірено спробу додавання сум у різних валютах. У такому випадку програма повідомляє про неможливість виконання операції.
